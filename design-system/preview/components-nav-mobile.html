Open. .site-header.nav-open. .header-actions drops below the top row; nav links stack as 2.75rem rows; aria-expanded="true"; active link uses aria-current="page"; CTA is calmer (ghost) and separated by a hairline so it does not dominate.

Class / state pattern

.site-headerRoot header element.
.site-header.nav-openOpen-state modifier on the root.
.header-topFirst row — brand + toggle (+ inline nav at desktop).
.header-actionsNav + CTA group. Hidden when closed, stacked when open. id="site-nav" is the target of aria-controls.
[data-nav-toggle]Hamburger button. Carries aria-expanded, aria-controls, and an aria-label that swaps between “Open menu” and “Close menu”.
.header-cta“Explore workflows” → /client-workflow-systems/. Restyled as a ghost link inside the open menu.
.brand-taglineHidden at ≤ 820px so the closed row stays compact.

Production note. The production site wires [data-nav-toggle] with a tiny vanilla-JS handler in layouts/partials/site-script.html that toggles the nav-open class on .site-header and flips aria-expanded. The UI kit (ui_kits/website/index.html and Header.jsx) uses React state to do the same thing; markup, classes, and ARIA stay identical. This preview is static — both states are rendered side-by-side so the behavior is visible without resizing.
