Feature image SVG templates live here as the editable source of truth for the scripted SVG workflow.

The directory structure mirrors `static/images/features/`.

Regenerate the served SVG feature images with:

```powershell
powershell -ExecutionPolicy Bypass -File tools/generate-feature-images.ps1
```

For the preferred no-API local raster workflow, use [tools/README-feature-images.md](../README-feature-images.md).
