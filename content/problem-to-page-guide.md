Use this page when you can name a specific operational problem but do not know which SoloOpsGuide resource addresses it. Match the symptom to a first resource, then use the second step only when it fits the result.

If the problem is broader than one symptom, such as "my whole client process feels loose," start with [Freelance client workflow system: inquiry to final payment](/workflows/freelance-client-workflow-system-inquiry-to-final-payment/). This routing guide is for a narrower, named blocker.

## How to use this page

- Scan the "Problem" column for the closest match to your actual symptom.
- Open the page in the "Read first" column.
- Use the "Next if needed" page only when the first page sends you there directly.
- Read only the row that matches the problem you need to solve.

## When this page is the right starting point

Use this page when:

- you already know the symptom, not the category,
- you want one relevant starting resource instead of browsing every collection,
- a broad collection gave you too many options for the specific blocker you have.

If the whole lifecycle still feels unclear, start with [Freelance client workflow system: inquiry to final payment](/workflows/freelance-client-workflow-system-inquiry-to-final-payment/). It covers the broader sequence that this routing page assumes you already understand.
