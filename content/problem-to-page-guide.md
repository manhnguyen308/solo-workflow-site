This page is for the moment when you already have a specific operational problem in mind but are not sure which page on SoloOpsGuide answers it best. Use the tables below to translate a real symptom into the strongest first page, then follow the second step only if there is a clear next move.

If your problem is broader than one symptom — "my whole client process feels loose" — start with the [Freelance Client Workflow System anchor](/workflows/freelance-client-workflow-system-inquiry-to-final-payment/) instead. This guide exists for narrower, named blockers.

## How to use this page

- Scan the "Problem" column for the closest match to your actual symptom.
- Open the page in the "Read first" column.
- Use the "Next if needed" page only when the first page sends you there directly.
- Do not try to read every row — this is a routing tool, not a reading list.

## When this page is the right starting point

Use this page when:

- you already know the symptom, not the category,
- you want the single best page to open next rather than a cluster tour,
- you tried a hub and it gave you too many options for the specific blocker you have.

Start somewhere else first if the whole lifecycle still feels unclear — the [Freelance Client Workflow System anchor](/workflows/freelance-client-workflow-system-inquiry-to-final-payment/) is the broader starting guide, and this page is narrower on purpose.
