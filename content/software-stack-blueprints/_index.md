Use these pages after you understand your workflow stages. The goal is to choose a stack that supports the work, not to collect more tools.

## Start here

1. Use [Software Stack Blueprint: Solo Freelancer (Lean Budget)](/guides/software-stack-blueprint-solo-freelancer-lean-budget/) for a solo baseline.
2. Use [Software Stack Blueprint: Consultant + VA Collaboration Setup](/guides/software-stack-blueprint-consultant--va-collaboration-setup/) if one operator now owns admin support through a VA.
3. Use [How to Migrate from Scattered Tools to One Workflow System](/guides/how-to-migrate-from-scattered-tools-to-one-workflow-system/) if your current stack is already fragmented.

## Decide by question

- If you do not know where active client truth should live, read [CRM vs Project Management Tool for Client Workflows](/comparisons/crm-vs-project-management-tool-for-client-workflows/).
- If you already know you are PM-first and need a delivery workspace decision, read [Notion vs ClickUp for Solo Client Delivery](/comparisons/notion-vs-clickup-for-solo-client-delivery/).
- If your issue is workflow quality rather than tool choice, go back to [Freelance Client Workflow System: Inquiry to Final Payment](/workflows/freelance-client-workflow-system-inquiry-to-final-payment/).
