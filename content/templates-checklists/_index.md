This section contains operating assets meant to be used inside an existing workflow. Open these pages when you want a practical next action, not a theory page.

## Start here

1. Use [Client Onboarding Checklist for Freelancers and Consultants](/templates/client-onboarding-checklist-for-freelancers-and-consultants/) after contract signing.
2. Use [Delivery QA Checklist Before Client Handoff](/templates/delivery-qa-checklist-before-client-handoff/) before every milestone or final delivery.
3. Use [Invoice and Payment Workflow Checklist for Service Businesses](/templates/invoice-and-payment-workflow-checklist-for-service-businesses/) when billing needs to become predictable.
4. Use [Client Offboarding + Testimonial Request Template](/templates/client-offboarding--testimonial-request-template/) to close cleanly and create follow-on value.
