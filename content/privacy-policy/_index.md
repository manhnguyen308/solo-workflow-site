SoloOpsGuide does not offer reader accounts, a contact form, a newsletter form, or a comment system. The current site code does not enable an audience analytics provider or advertising scripts.

Loading the site still involves the hosting provider and an external font service, as described below.

## Hosting and request data

SoloOpsGuide is delivered through Cloudflare Pages. A request to the site can expose technical request data to Cloudflare, including an IP address, requested URL, browser or device information, referral information, and security-related data.

Cloudflare describes its handling of end-user and log data in its [Privacy policy](https://www.cloudflare.com/privacypolicy/).

## Site search

Search loads a same-origin site index and filters it in the browser. When a reader submits a search form, the query appears in the page URL and may therefore be included in browser history and hosting request logs.

SoloOpsGuide does not send the query to a separate search provider in the current implementation.

## Google Fonts

Pages request Public Sans, Source Serif 4, and JetBrains Mono through the Google Fonts stylesheet and font domains. The browser therefore connects to Google when those files are requested.

Google explains the service request flow in its [Google Fonts technical considerations](https://developers.google.com/fonts/docs/technical_considerations) and describes its data practices in the [Google Privacy policy](https://policies.google.com/privacy).

## Cookies, analytics, and advertising

The current site code does not set a first-party account or preference cookie. No audience analytics provider, advertising script, affiliate tracking link, or ad publisher identifier is active in the site configuration.

Cloudflare and Google apply their own policies to requests handled by their services. Browser controls, content blockers, and network settings may limit some third-party requests, though doing so can affect font loading or other site behavior.

## Information submitted directly

There is no current form or monitored public address through which a reader can submit personal data to SoloOpsGuide. Do not send sensitive information to an address or account that merely claims to represent the site.

[Contact availability](/contact/) records the current limitation. Any published submission channel must identify what it collects, why it is needed, who processes it, and how long it is retained.

## External links

Opening an external link places the reader under the external site's privacy practices. Review that provider's policy before submitting information or creating an account.

## Changes to this policy

This page should change when the site's hosting, fonts, analytics, advertising, search, or contact practices change materially. The updated date records the latest meaningful revision.
